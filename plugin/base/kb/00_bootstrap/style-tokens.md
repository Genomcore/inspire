# Style tokens — the project's own R6 and R7 words

_The words `prose-style.sh` flags as history (R6) or as an intensifier (R7), in the
project's `output_language`. An English project already checks the built-in lists of
[writing-style](../../.claude/skills/_references/writing-style.md), and a row here adds
to them. Any other language checks only the rows here. A token belongs on this list only
if it almost never states present behavior: a check that fires on healthy prose is read
as noise._
